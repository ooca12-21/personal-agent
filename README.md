# Personal Agent

手机个人事务管理工具，使用本地规则，无AI接口或API费用。

## 自由输入待办

点击“＋待办”，输入具体事项，例如：

今天扔垃圾，明天洗衣服，整理桌面
周三读论文
下周工作日背单词
10月12日到10月14日整理文献

支持今天/明天/后天、周几、本周/下周、明确日期、多日期、每天、工作日、周末及最多31天的日期范围。
同一行没有新日期的事项沿用最近明确日期；换行重新计算，无日期进入待安排。
“每天”默认从参考日开始7天。识别结果先预览，允许编辑名称、日期和预计耗时，确认后才保存。
相同名称与日期的任务不重复添加，已有完成记录保留。无效日期会报错，部分未支持的日期表达会要求手动选择。
规则只能整理具体事项，不会推导复杂目标的执行步骤。

论文示例模板仍可使用；确认新论文模板会替换旧论文示例，但保留自由添加的任务。
数据保存到当前浏览器的localStorage，不支持跨设备同步；可导出JSON，暂不支持导入。

https://ooca12-21.github.io/personal-agent/
GitHub Pages 从 main 分支根目录发布。
入口为 index.html，规则模块为 rules.js；不需要构建或安装依赖。
