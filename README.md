# Personal Agent

访问：https://ooca12-21.github.io/personal-agent/

手机适配的本地个人规划网页。无需AI、API key或后台。

- 首页：自由输入添加待办；无日期或只写时间默认今天。
- 计划汇总：月历，上/下月切换；点日期显示该日，再点相同日期返回七天清单。红色标记该日的重要待办。
- 选定日期的任务可删除、添加该日子任务，其他日期输入会被拦截。
- 未完成任务与子任务可拖动，手机可用上下箭头调整优先级；排序持久保存。
- 标签：固定红色“重要”，预置蓝色“学习”、黄色“工作”；自定义标签可命名并选择蓝、黄、绿、紫、灰色。
- 主任务与子任务可添加/编辑300字以内备注，完成后仍可编辑备注。子任务备注不展开，有备注的按钮标红；子任务不显示安排日期，具体时间仍显示。
- 事项记录：按完成日期/时间归档，支持关键字搜索；完成任务内容不可修改，可删除完成记录并从已删除任务还原。
- 完成主任务会一并完成其未完成的子任务，分别归档。
- 已删除任务：可还原、永久删除单条或清空。永久删除须在弹窗确认，事项记录不受影响。
- 导出JSON保存记录。浏览器旧记录继续读取；旧完成记录未知的时间显示“完成时间未记录”。

数据仅存在当前浏览器localStorage（pa-prototype-v1），不上传GitHub，不跨设备同步。清除网站数据会丢失本地记录。

规则识别支持今天、明天、星期、日期、日期范围、重复及“从今天开始，往后一周完成文献综述”等持续任务。七天含开始当天；持续范围最多31天。不连接AI，不推断研究步骤。

部署：GitHub Pages从main根目录读取index.html、rules.js、model.js、app.js。

首页与计划页的任务操作保持单排，窄屏横向滑动。事项记录主任务按钮为“备注”。

事项记录：单独完成的子任务先独立显示，总任务完成后自动嵌套在总任务下，不重复展示；原完成时间及备注不变。搜索子任务会带出总任务上下文。旧记录按任务ID补充父子关系。

允许相同名称、日期、时间的主任务和子任务重复存在，同次输入或多次添加均保留，每条使用独立ID。
