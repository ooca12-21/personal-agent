# Personal Agent

访问：https://ooca12-21.github.io/personal-agent/

手机适配的个人规划网页，支持本地使用及 GitHub 登录后的 Supabase 云端同步，不接入 AI。

- 首页：自由输入添加待办；无日期或只写时间默认今天，支持昨天、前天及明确过去日期。跨日期范围每天生成独立待办，完成或删除只影响对应日期。
- 计划汇总：月历，上/下月切换；点日期显示该日，再点相同日期返回七天清单。红色标记该日的重要待办。
- 选定日期后可添加当天待办，填写时间、标签（含自定义标签）和300字以内备注；可选择过去日期。现有任务可删除、添加该日子任务，其他日期输入会被拦截。
- 未完成任务与子任务可拖动，手机可用上下箭头调整优先级；排序持久保存。
- 标签：仅红色“重要”固定不可删除，其他预置和自定义标签模板均可在“管理标签”中删除、编辑名字；只影响以后选用的模板，已使用标签的任务/子任务/事项记录保留原名称和颜色。自定义标签可命名，选择预设颜色或输入 HEX（3位或6位，可带#），实时预览颜色。
- 主任务与子任务可添加/编辑300字以内备注，完成后仍可编辑备注。子任务备注不展开，有备注的按钮标红；子任务不显示安排日期，具体时间仍显示。
- 事项记录：按设定日期分组，设定时间用大字，实际完成时间在旁边以小字显示，子任务不显示时间；支持关键字搜索；完成任务内容不可修改，可删除完成记录并从已删除任务还原。
- 完成主任务会一并完成其未完成的子任务，分别归档。
- 已删除任务：可还原、永久删除单条或清空。永久删除须在弹窗确认，事项记录不受影响。
- 导出JSON保存记录。浏览器旧记录继续读取；旧完成记录未知的时间显示“完成时间未记录”。

未登录的数据保存在当前浏览器 localStorage（pa-prototype-v1）。登录后使用各账号独立的本地缓存和 Supabase 私有数据表；任务数据不上传 GitHub。首次登录可选择将本地原有记录合并到账号。清除浏览器数据会丢失未同步的修改。

规则识别支持今天、明天、星期、日期、日期范围、重复及“从今天开始，往后一周完成文献综述”等跨日任务。七天含开始当天，每天独立生成；输入日期范围最多31天。已有未完成持续任务自动转换，备注和标签保留，子任务按安排日期分配；已完成历史不拆分。不连接AI，不推断研究步骤。

部署：GitHub Pages 从 main 根目录读取 HTML 和 JS；Supabase 配置见 CLOUD-SYNC.md。

事项记录主任务按钮为“备注”。

事项记录：单独完成的子任务先独立显示，总任务完成后自动嵌套在总任务下，不重复展示；原完成时间及备注不变。搜索子任务会带出总任务上下文。旧记录按任务ID补充父子关系。

允许相同名称、日期、时间的主任务和子任务重复存在，同次输入或多次添加均保留，每条使用独立ID。

首页今日待办操作分两排：第一排常用操作和标签，第二排备注及优先级上下箭头；子任务也采用相同布局。计划汇总保持单排。

日期范围规则（项目记录，不新增网页提示）：支持 M.D-M.D、M.D至/到M.D、M月D日至/到M月D日、D号到D号、从今天起到D号。包含首尾日期，每天独立生成；日期前缀不进入任务标题。无年份使用参考年，日号使用起始月份或参考月份；明确月日跨年可顺延年。10号到18号表示当月10–18日共9天；从14日起应写14号到18号。非法日期、倒序范围、超过31天阻止添加。事项记录隐藏旧任务时间跨度，保留设定日期与当天时间；日历选中后的列表只显示“当日待办”标题，不重复日期标题。

范围表达补充：连接符支持至、到、—、–、-、～、~；结束日期可省略月份（如10.10-18、10月10日–18日），继承起始月份。日与号等价；支持中文数字月/日（十月十日至十月十八日）、自…起至…止。范围后“这段时间”“这个时间段”（含逗号间隔）作为时间说明去除，不进入标题。用户列出的15种范围×日/号×5种附加词组合共150项测试通过，均生成10月10–18日9项推进文献综述。其他月份同样适用，不添加网页规则文案。

标签模板与任务标签分离：任务保存使用时的标签名称/颜色快照；模板删除/改名不改变已有快照。旧记录迁移保存现有标签信息。删除模板后，新任务不再显示该模板；旧任务编辑标签仍可保留已有标签。历史搜索使用任务保存的标签名称。模板删除标记参与云端同步；模板“重要”固定不可编辑或删除。
