# Personal Agent prototype

手机个人规划交互原型。打开 index.html 即可预览。

功能：论文示例计划编辑与确认、今日任务完成/撤销、浏览器本地保存、延期预览、记录导出。
限制：固定示例模板，未接入真实 AI；无登录、云端同步或通知；暂只保存一个目标。

## 静态部署

入口 index.html 在仓库根目录，无安装命令或构建命令。
Vercel 使用 Other 静态项目，关闭构建命令，输出目录使用项目根目录。
GitHub Pages 可选择 main 分支的 /(root) 目录；仓库私有不等于发布网页私有。

计划数据保存在使用者自己的浏览器，不包含在代码仓库中。源码包含论文主题等示例文字；公开发布前应检查这些文字。
